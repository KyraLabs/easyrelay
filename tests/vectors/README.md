# Test vectors

Fixed inputs with known-correct outputs, taken from outside this project. The rule they exist
to serve is in [docs/testing.md](../../docs/testing.md): a vector generated by easyrelay proves
only that easyrelay agrees with itself, which is exactly the failure being guarded against.

They run on every `zig build test`.

## `bip340.csv`

The official BIP-340 Schnorr suite, verbatim.

| | |
| --- | --- |
| Source | `https://raw.githubusercontent.com/bitcoin/bips/master/bip-0340/test-vectors.csv` |
| Retrieved | 2026-08-24 |
| Contents | 19 vectors: 9 that must verify, 10 that must be rejected |
| Licence | BIP-340 is BSD-2-Clause; its code and data are `BSD-2-Clause OR MIT OR CC0-1.0` |

The ten rejection vectors are the valuable half. They cover a public key off the curve, a
negated message, a negated `s`, an `sG - eP` at infinity, and field-size and curve-order
boundaries — the cases where a hand-rolled implementation returns true and a correct one does
not. easyrelay does not implement Schnorr ([ADR-0006](../../docs/adr/0006-cryptography.md)),
so what these check is that the vendored `libsecp256k1` still behaves after a dependency
upgrade.

Refreshing it: fetch the file again. Its row count is asserted by the suite, so a truncated
download fails rather than silently checking less.

## `events.json`

Six real events collected from public relays, each with the id its author published.

| | |
| --- | --- |
| Relays | `nos.lol`, and `nostr.mom` / `offchain.pub` for the kind 1 |
| Collected | 2026-08-24 |
| Selected from | 2,934 distinct events, every one of which recomputed to its published id |

They were chosen to cover the escaping rules where a general-purpose JSON encoder diverges from
NIP-01, because that divergence is invisible in testing and fatal in production — a wrong id
makes every event the relay serves unusable while the relay looks healthy.

| Event | Kind | Covers |
| --- | --- | --- |
| `20aaa157` | 7 | A single astral-plane emoji: four UTF-8 bytes emitted verbatim, not `\uXXXX` |
| `bd387221` | 1 | An embedded line break, and three-byte UTF-8 |
| `bee6cb57` | 0 | Quotes, from a profile document carried as a JSON string |
| `659e50d1` | 0 | Backslashes and forward slashes, and no tags at all |
| `35f357f1` | 3 | Empty content and an empty tag array |
| `a62f459b` | 3 | Empty content with 25 tags |

A test asserts this coverage still holds, so refreshing the corpus into one that no longer
exercises these fails rather than quietly weakening the suite.

**Tab has no real-event vector.** A tab in `content` occurred once in the 2,934 events swept,
in a 33,000-character article that is not worth vendoring. Tab is also the least dangerous of
the seven escapes: every JSON encoder emits `\t` exactly as NIP-01 requires, so it is not a
divergence case. It is covered instead by the specification-derived test in `vectors.zig`,
which asserts all seven escapes and a raw control byte against bytes transcribed from
[docs/protocol.md](../../docs/protocol.md) — non-circular, because the expected output is
written from the specification rather than produced by any implementation.

Refreshing it: any set of real events works, as long as the coverage test still passes. Every
event is checked twice by the suite — its id is recomputed from its own fields and its
signature is verified — so a corrupted or invented event fails immediately.
